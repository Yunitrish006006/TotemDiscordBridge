# TotemDiscordBridge

Optional Discord integration for Totem. It depends on TotemCore only and must
start without Remnant, Automata or Nexus. DeadRecall remains the compatibility
bundle while this pilot is validated standalone and in lockstep.

`0.1.2` is the current candidate built against the external TotemCore `0.2.0`
artifact. The published `0.1.1` graph remains the rollback baseline and has
already completed its two-release observation.
